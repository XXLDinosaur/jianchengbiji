# 简成笔记 0.4.0 开发预览

本轮只更新开发预览，不制作安装包。启动入口：I:\软件开发\简成笔记.lnk。原成简未修改。

## 左侧栏与仓库

文件和导航合并为同一个侧栏，点击顶部“文件 / 导航”切换。导航保留目录、查找、替换。
双击文件树中的文档或文件夹，可原位修改名称；Enter 确认、Escape 取消。
左下角“仓库”旁是紧凑的选择按钮，菜单向上展开；“打开 / 新建仓库”在菜单底部。
文件管理的右键操作继续保留。

## 标签与编辑

标签分组和加号入口已移除。拖动标签可调整顺序，重启会恢复顺序。Ctrl+T、Ctrl+W 和 Ctrl+Tab 快捷键继续有效。
顶部品牌栏和编辑工具栏已压缩。工具栏不再显示目录、查找、替换、链接按钮；查找替换可从导航进入，也可按 Ctrl+F / Ctrl+H。

## 文档右键菜单

文档内右键包含复制、粘贴、剪切、链接。选中文字后执行复制或剪切；粘贴插入当前位置。
“链接”（或 Ctrl+K）默认从当前仓库挑选已有文档。选中文字时将它变为链接，没有选中文字时插入文档名；点击后在新标签打开目标文档。
本地文档链接使用 note: 仓库相对路径，保存到 Markdown 中；这是成简笔记的文档链接格式，跨软件不一定可直接打开。
网址双击后在默认浏览器打开。右键网址可取消跳转，变为纯文本外观；再右键选“跳转链接”即可恢复。取消标记也会保存到 Markdown，重新打开仍有效。

## 主题

选择主题后点击“完成”，选中的方案就是以后启动使用的主题，不再显示“设为默认”按钮。

## 数据

设置与草稿位于 %APPDATA%\ChengjianNotes；仓库文件仍是普通本地文件，不包含云同步。
重命名或移动文件后，其他文档内已有的本地文档链接不会自动更新，需重新选择链接目标。

## 验证命令

npm run build
npm test
npm run test:vault
npm run test:layout

## 0.4.0 更新

软件名改为“简成笔记”，双竹叶渐变图标为透明背景。为保留已有设置和草稿，项目路径与数据目录保持原位置。

“仓库”菜单现在进入“管理仓库”：创建、打开、仓库显示名称修改、移动、复制 ID、系统定位、从列表移除。列表移除不删除文件。跨盘移动会校验复制后的文件内容。重命名修改的是仓库的显示名称，不改动实际文件夹名字。

文件树移除了固定 500 毫秒等待，并复用节点和目录读取结果；重新聚焦窗口、刷新或文件操作后更新缓存。

标签不显示扩展名，右键可关闭其他所有标签。未保存修改仍会确认，取消会停止批量关闭。

下拉选项与弹窗采用主题色玻璃样式；系统文件/文件夹选择器使用 Windows 原生界面。文档链接统一显示主题色下划线。

0.8.0 修正：旧版保存的竹绿自定义方案若缺少链接颜色，自动补为深绿色 #19492F，避免沿用浅绿色主题色；已明确设置的链接颜色和其他主题参数保持不变。

启动行为：没有可恢复文档时显示空白工作区，不创建未命名标签；关闭最后一个文档和切换仓库后同样保持空白。已有文档、草稿仍按会话恢复，Ctrl+N / Ctrl+T 可主动新建。

## 2026-10-07：保存保真与分享导出

- 图片尺寸用 HTML img width 保存；复杂表格保留 HTML、合并单元格和列宽；空白段落用 <p></p> 表达，防止 Markdown 转换时折叠。
- 拖入、粘贴或选择的图片仍写入文档同名 .assets 文件夹，使用相对路径。未命名草稿先暂存，首次保存后收集到 .assets。另存为时复制原文档所需的本地图片；缺失资源会明确提示，避免保存出缺图文档。带上文档及 .assets 文件夹即可搬迁。
- 顶部“导出”包含“复制为富文本”“导出 A4 PDF”“导出独立 HTML”，只处理当前标签页；操作期间锁定标签切换，避免资源串用。
- PDF / 打印采用白底 A4、页眉文档名、当前页 / 总页数，并避免标题与后文分离。超出单页高度的块仍可能跨页。
- HTML 内嵌 CSS 和图片，可单文件离线查看；外部链接本身仍需联网。不会打包整个仓库，也不会把内部文档链接的目标文件嵌入 HTML。
- 富文本剪贴板包含 HTML 和纯文本，图片为 Base64，SVG 复制时转换为 PNG。目标编辑器可能过滤图片或样式，不保证微信公众号、知乎、飞书、语雀、Word 各版本无损粘贴；目前未逐个平台实测。
- 网络图片需成功下载；资源限制 500 张、约 80 MB，读取或解码失败时中止导出。PDF/HTML 不改变原 Markdown。
